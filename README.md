# PixelPop Storybooks

Offline story packs for PixelPop.

## Little Red Riding Hood

A six-part bedtime narration with matching wide illustrations for the 64x32 display.

- Audio: 16 kHz, mono, 16-bit WAV
- Illustrations: 128x64 JPEG
- Segments: intro, forest, wolf, cottage, evening, ending

## Additional stories in production

Cinderella, Thumbelina, Pinocchio and Snow White have complete twelve-page narration scripts. Three books have both illustration editions prepared; Pinocchio artwork and all new recorded narration remain pending. These drafts are explicitly not installable.
